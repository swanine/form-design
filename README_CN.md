# 表单设计器 Form Design

一个基于 Vue 3 + TypeScript + Vite 的可视化表单设计器。

## 功能特性

- 🎨 **拖拽设计**：通过拖拽方式快速创建表单
- 🎯 **丰富组件**：支持多种表单组件类型
  - 单行文本
  - 多行文本
  - 计数器
  - 下拉选择
  - 日期选择
  - 颜色选择
  - 单选框
  - 多选框
- ⚙️ **实时配置**：点击组件即可配置属性
- 👀 **实时预览**：随时预览表单效果
- 💾 **状态管理**：使用 Vuex 管理表单状态

## 技术栈

- Vue 3
- TypeScript
- Vite
- Element Plus
- Vuex
- Vue Router
- VueDraggable
- Intro.js

## 快速开始

### 安装依赖

```bash
pnpm install
```

### 开发模式

```bash
pnpm dev
```

### 构建生产版本

```bash
pnpm build
```

## 使用说明

1. **添加字段**：从左侧组件面板拖拽字段到表单设计区域
2. **配置字段**：点击表单中的字段，在右侧配置面板修改属性
3. **调整布局**：在配置面板中调整字段宽度（25%、50%、75%、100%）
4. **排序字段**：在表单设计区域拖拽字段进行排序
5. **预览表单**：点击顶部"预览"按钮查看表单效果
6. **删除字段**：在配置面板中点击"删除字段"按钮
